MiniLeetCode is a mini LeetCode-style full-stack application. 
The goal of this project is to create a simple version of a 
coding challenge platform where users can solve programming problems, 
submit different code solutions, and see how other users solved the same problems.

The goal of this project is not recreae 
All leetcode but to build a smaller and simpler version while exploring the different parts of a 
full-stack application, including frontend development, REST APIs, authentication, 
databases, secure password storage, code execution, and AI integration.
